# Einar Viandas

Proyecto final del curso de Desarrollo Web de Coderhouse. Es un sitio estático de 5 páginas para un emprendimiento de viandas caseras.

## Links

- Sitio en Netlify: https://pre-entrega-einar.netlify.app/
- Sitio en GitHub Pages: https://ignaciodellacanonica-rgb.github.io/Pre-Entregas-coder/
- Repositorio: https://github.com/ignaciodellacanonica-rgb/Pre-Entregas-coder

## Páginas

- `index.html`: inicio con promos, beneficios y tarjetas de viandas
- `pages/nosotros.html`: sobreel negocio
- `pages/viandas.html`: menú de viandas
- `pages/preguntas-frecuentes.html`: preguntas frecuentes con acordeón
- `pages/contacto.html`: formulario de contacto
